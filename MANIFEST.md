# Reproducibility package manifest

This directory is the standalone code-and-artifact package for the manuscript
`Expected-Exposure DR-Submodular Rewards for Model-Based Reinforcement
Learning via Occupancy Continuous Greedy`.

## Executable modules

- `run_experiments.py`: main GridWorld and stochastic-allocation experiments,
  including the standard OCG figures and GridWorld scaling outputs.
- `run_direct_cvx.py`: Direct-CVX numerical references for the soft and log
  utilities, with solver diagnostics and acceptance checks.
- `run_frank_wolfe.py`: Frank-Wolfe baseline with golden-section line search.
- `run_allocation_scaling.py`: allocation scaling check.
- `make_gap_to_reference.py`: per-instance OCG/FW gap table and figure.
- `reproduce_all.py`: ordered full-suite driver.
- `validate_outputs.py`: checks committed/regenerated artifact counts and key
  numerical diagnostics.

## Required dependencies

See `requirements.txt`: NumPy, pandas, Matplotlib, and CVXPY. CVXPY uses
Clarabel by default and falls back to SCS when the recorded fallback path is
needed.

## Stored results

The `results/` directory contains the frozen CSV/JSON outputs for:

- main GridWorld and allocation experiments;
- GridWorld and allocation scaling checks;
- Direct-CVX references;
- Frank-Wolfe comparisons;
- gap-to-reference summaries.

The `figures/` directory contains the corresponding PNG/PDF figures,
including the gap-to-reference figure generated by the package itself.

## Reproduction entry point

From this directory:

```bash
python -m pip install -r requirements.txt
python reproduce_all.py
python validate_outputs.py
```

See `README.md` for the full protocol, seeds, solver tolerances, output map,
and interpretation limits.
